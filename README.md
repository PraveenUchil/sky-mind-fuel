# SKY* — MIND FUEL

A custom, responsive, single-page website for the SKY Mind Fuel running campaign.

## Preview
Open `index.html` in any browser. No build tools are required.

## Publish free on GitHub Pages
1. Sign in to https://github.com and create a **public** repository named `sky-mind-fuel` (or another name).
2. Upload `index.html` to the **root** of the repository. Commit the file.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**; choose **main** and **/(root)**; save.
5. GitHub will provide a URL resembling `https://YOUR-USERNAME.github.io/sky-mind-fuel/` once deployment completes.
6. Test the site on your phone, then generate a QR code using the final live URL. Keep the same repository name and URL when editing the page.

## Edit content
Open `index.html` in a text editor or GitHub's file editor. Search for the relevant heading and edit the paragraph text. Commit changes to publish updates at the same URL.
